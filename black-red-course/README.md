# Black & Red Course Website (Canva replica)

Static HTML/CSS replica of [studio-amber Canva course landing page](https://studio-amber.my.canva.site/black-red-course-website) with photo placeholders instead of stock images.

## Preview

```bash
cd black-red-course
python3 -m http.server 8765
# open http://127.0.0.1:8765
```

## Files

- `index.html` — full one-page sales site
- `styles.css` — layout & brand styles
- `main.js` — early-bird countdown
