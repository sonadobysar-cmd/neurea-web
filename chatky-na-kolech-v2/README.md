# FLAX — tiny houses na míru

Druhý samostatný návrh webu s teplým resortním vizuálem a interaktivním konfigurátorem tiny houses.

## Dev

```bash
cd chatky-na-kolech-v2
npm install
npm run dev
```

Otevři [http://127.0.0.1:3100](http://127.0.0.1:3100)

## Stránky

- `/` — FLAX homepage
- `/konfigurator` — živý konfigurátor (model, fasáda, střecha, interiér, výbava)
- `/realizace` — portfolio
- `/atelier` — materiály a výroba
