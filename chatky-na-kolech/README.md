# Chatky na kolech

Prémiový web s interaktivním konfigurátorem tiny houses.

## Dev

```bash
cd chatky-na-kolech
npm install
npm run dev
```

Otevři [http://127.0.0.1:3100](http://127.0.0.1:3100)

## Stránky

- `/` — cinematic home
- `/konfigurator` — živý konfigurátor (model, fasáda, střecha, interiér, výbava)
- `/realizace` — portfolio
- `/atelier` — o nás / dílna
