# Kouzlíme s Robinem — vizitka v1 (Claude HTML)

Statický one-page web z exportu `kouzlime-navrh-5-vizitka_2.html` s vylepšenými animacemi.

## Vercel

1. **Add New Project** → repo `neurea-web`
2. **Root Directory:** `kouzlimesrobinem1`
3. **Project Name:** `kouzlimesrobinem1`

## Rebuild po úpravách zdroje

```bash
python3 scripts/build-kouzlimesrobinem1.py
```

Zdrojový HTML export: `~/Downloads/kouzlime-navrh-5-vizitka_2.html`
