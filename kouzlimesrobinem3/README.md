# Kouzlíme s Robinem — návrh 3 (moderní)

Samostatný web — **Lovable „Modern Magic“** design. Není Neurea, není stánková verze (`kouzlimesrobinem`).

## Vercel (niadobysar)

1. [vercel.com](https://vercel.com) → účet **niadobysar**
2. **Add New Project** → repo `neurea-web`
3. **Root Directory:** `kouzlimesrobinem3`
4. **Project Name:** `kouzlimesrobinem3` → `https://kouzlimesrobinem3.vercel.app`
5. Deploy

## Lokálně

```bash
cd kouzlimesrobinem3
npm install
npm run dev
```
