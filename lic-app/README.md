# Líc

**Tvoje tvář. Sedí. Neskače.**

Webová appka / vizuální MVP: shorty z dlouhých videí, stabilní beauty lock, světlo a české titulky.

## Spuštění

```bash
cd lic-app
npm run dev
```

Otevři [http://127.0.0.1:5177](http://127.0.0.1:5177).

Nebo stačí otevřít `index.html` v prohlížeči.

## Co umí (demo UI)

- Landing s brand hero
- Studio: výběr háčků, beauty (Natural / Glow / Glam), světlo, styly titulků CZ
- Face lock indikátor (stabilní tracking UX)
- Export toast (mock)

Další krok: napojit ASR + identity-locked beauty pipeline.
